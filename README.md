# Personal Todo App

A minimal offline-first todo app built with React Native and Expo for personal task management.

## Tech Stack

- React Native
- Expo
- TypeScript
- SQLite

## Features

- Create, update, and delete tasks
- Local SQLite database (offline support)
- Timed tasks
- Multiple tabs navigation
- Search Bar

## Installation

- git clone
- npm install
- npm run test (Start development server)

## Build APK

- expo login (Login to Expo)
- npm run build (Build Android APK)
